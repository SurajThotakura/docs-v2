Auth0 Universal Components for native apps ship pre-built, embeddable UI for identity flows on iOS (SwiftUI) and Android (Jetpack Compose). This page covers installation and platform requirements. Once the SDK is installed, continue to [Build a Self-Service Account Security Interface](/docs/get-started/universal-components/my-account/build-account-security) to wire authentication and render the auth-methods management UI.

## Install the SDK

<Tabs>
<Tab title="iOS">

The iOS SDK is distributed as `Auth0UniversalComponents`. Swift Package Manager is the recommended installer.

### Swift Package Manager

In Xcode, open **File → Add Package Dependencies** and enter:

```
https://github.com/auth0/ui-components-ios.git
```

Select version `1.0.0` or later, then add `Auth0UniversalComponents` to your app target.

### CocoaPods

Add the pod to your `Podfile`:

```ruby Podfile
pod 'Auth0UniversalComponents', '~> 1.0.0'
```

Then run:

```bash
pod install
```

<Callout icon="file-lines" color="#0EA5E9" iconType="regular">
  **Known issue:** The 1.0.0 CocoaPods release omits bundled Media, Colors, and Fonts resources. If your UI renders without the expected styling, switch to Swift Package Manager until the next podspec release.
</Callout>

### Carthage

Add the following to your `Cartfile`:

```
github "auth0/ui-components-ios" ~> 1.0.0
```

Then run:

```bash
carthage update --use-xcframeworks
```

### Verify the install

Import the module in a Swift file to confirm the framework resolves:

```swift
import Auth0UniversalComponents
```

### Sample app

See the `AppUIComponents/` target in [ui-components-ios](https://github.com/auth0/ui-components-ios) for a reference implementation, including `AppUIComponentsApp.swift` (SDK initialization) and `Common/ThemeManager.swift` (runtime theme switching).

</Tab>

<Tab title="Android">

The Android SDK is distributed through Maven Central as `com.auth0.universalcomponents:universal-components`.

### Gradle

Add Maven Central to your `settings.gradle` (or `settings.gradle.kts`) if it is not already listed:

```groovy settings.gradle
dependencyResolutionManagement {
    repositories {
        mavenCentral()
        google()
    }
}
```

Then add the dependency to your module-level `build.gradle` (or `build.gradle.kts`):

```groovy build.gradle
dependencies {
    implementation 'com.auth0.universalcomponents:universal-components:1.0.0'
}
```

### Configure Compose

Ensure Compose is enabled in your module-level `build.gradle`:

```groovy build.gradle
android {
    buildFeatures {
        compose = true
    }
}
```

See the `/app/` module in [ui-components-android](https://github.com/auth0/universal-components-android) for a reference implementation, including `MainActivity.kt` (Auth0 SDK setup and SDK initialization) and `LoginSecurityScreen.kt` (renders `AuthenticatorSettingsComponent`).
