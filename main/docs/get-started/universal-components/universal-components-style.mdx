Auth0 Universal Components are built on a flexible design system that utilizes [Tailwind CSS](https://tailwindcss.com/docs/installation/using-vite) and [Radix UI primitives](https://www.radix-ui.com/primitives/docs/overview/introduction). Styling is orchestrated through the [`Auth0ComponentProvider`](/docs/get-started/universal-components/auth0-component-provider) to allow you to choose between high-level presets or fine-grained CSS variable overrides.

This architecture ensures that your identity flows look and feel like native parts of your application.

## Get started

<Tabs>
  <Tab title="React">

1. Import the scoped stylesheet.

```tsx
import "@auth0/universal-components-react/styles";
```

2. Add your brand color.

```css
:root {
  --auth0-primary: #4f46e5; /* your brand color */
  --auth0-primary-foreground: #ffffff; /* text on buttons */
}
```

Done. All buttons, links, and active states now use your brand.

  <Tab title="Tailwind v4 / shadcn">

Auth0 Universal Components work natively with Tailwind v4 and shadcn. Instead of importing a pre-built stylesheet, your own Tailwind build generates the component CSS.

1. Add the source directive to your CSS file.

```css
@import "tailwindcss";
@import "@auth0/universal-components-react/tailwind";
@import "@auth0/universal-components-core/styles/globals.css";
```

The `tailwind` import contains `@source "./**/*.js"`, which tells your Tailwind build to scan Auth0's component files for class names like `bg-primary` and `text-muted-foreground`.

2. Map your theme variables.

If you're using shadcn, this is already in your CSS. Otherwise, add the `@theme` block that bridges your bare variable names to Tailwind's internal `--color-*` tokens:

```css
@theme inline {
  --color-background: var(--background);
  --color-foreground: var(--foreground);
  --color-primary: var(--primary);
  --color-primary-foreground: var(--primary-foreground);
  --color-card: var(--card);
  --color-card-foreground: var(--card-foreground);
  --color-accent: var(--accent);
  --color-accent-foreground: var(--accent-foreground);
  --color-muted: var(--muted);
  --color-muted-foreground: var(--muted-foreground);
  --color-border: var(--border);
  --color-ring: var(--ring);
}
```

3. Define your brand color.

```css
:root {
  --primary: #4f46e5; /* your brand color */
  --primary-foreground: #ffffff; /* text on buttons */
}
```

Done. Your Tailwind build generates the utility CSS, and your `:root` values flow through the `@theme` mapping into the components.

<Callout icon="file-lines" color="#0EA5E9" iconType="regular">
**Why bare `--primary` works here:** Your `@theme` block maps `--color-primary: var(--primary)`. Tailwind reads `--color-primary` and generates `.bg-primary { background-color: var(--color-primary) }`. The chain is: `--primary` → `--color-primary` → utility class. Auth0's pre-built CSS is not involved.

</Callout>

## Theme presets

Pass `themeSettings` to `Auth0ComponentProvider` to switch between built-in themes.

```tsx
<Auth0ComponentProvider
  themeSettings={{
    mode: "light", // 'light' | 'dark'
    theme: "default", // 'default' | 'minimal' | 'rounded'
  }}
>
  <App />
</Auth0ComponentProvider>
```

## CSS variable reference

All visual properties are driven by CSS custom properties. Override them in your stylesheet or via the `themeSettings.variables` prop.

<Callout icon="file-lines" color="#0EA5E9" iconType="regular">
**Color variable names depend on your setup.**

- **React / Next.js** (imported `styles.css`): Use `--auth0-*` prefixed names, e.g., `--auth0-primary`.
- **Tailwind v4 / shadcn**: Use bare names in your CSS, e.g., `--primary`.

Border radius, typography, and shadow variables use the same names everywhere.

</Callout>

## Style components

Every component accepts a `styling` prop for targeted overrides without affecting global styles.

<Callout icon="file-lines" color="#0EA5E9" iconType="regular">
The `styling` prop **always** uses `--auth0-*` prefixed names for colors, regardless of your CSS setup. This is because the prop sets inline styles directly on the component wrapper, bypassing both the scoped CSS and your Tailwind build.

</Callout>

```tsx
<SsoProviderTable
  styling={{
    variables: {
      common: {
        "--radius-lg": "16px",
      },
      light: {
        "--auth0-primary": "#059669",
        "--auth0-card": "#f8fafc",
      },
      dark: {
        "--auth0-primary": "#34d399",
        "--auth0-card": "#1e293b",
      },
    },
    classes: {
      "SsoProviderTable-header": "shadow-lg",
      "SsoProviderTable-table": "rounded-xl",
    },
  }}
/>
```

**When to use:**

- `variables` — CSS custom property overrides scoped to the component. Use `common` for radius and typography. Use `light`/`dark` for color overrides with `--auth0-*` prefixed names.
- `classes` — Tailwind or custom classes applied to specific component parts.

## Common customizations

### Brand colors

<Tabs>
  <Tab title="Scoped (React / Next.js)">
```css
:root {
  /* Using hex directly */
  --auth0-primary: #4f46e5;
  --auth0-primary-foreground: #ffffff;

  /* Or oklch for better color manipulation */
  --auth0-primary: oklch(50% 0.2 265); /* purple */
```

  </Tab>
  <Tab title="Tailwind v4 / shadcn">
```css

  --primary: #4f46e5;
  --primary-foreground: #ffffff;

  /* Or oklch for better color manipulation */
  --primary: oklch(50% 0.2 265); /* purple */
```

### Soft corners

For a more rounded aesthetic across all components:

```css
:root {
  --radius-lg: 16px; /* buttons, inputs */
  --radius-xl: 20px; /* cards */
  --radius-2xl: 24px; /* modals */
}
```

### Compact typography

For denser UIs:

```css
:root {
  --font-size-page-header: 1.75rem;
  --font-size-heading: 1.25rem;
  --font-size-title: 1rem;
  --font-size-body: 0.875rem;
}
```

## Dark mode

The components automatically respond to the `mode` setting in `themeSettings`. To sync with your app's dark mode:

```tsx
function App() {
  const [isDark, setIsDark] = useState(false);

  return (
    <Auth0ComponentProvider
      themeSettings={{
        mode: isDark ? "dark" : "light",
      }}
    >
      <YourApp />
    </Auth0ComponentProvider>
  );
}
```

Or use system preference:

```tsx
const prefersDark = window.matchMedia("(prefers-color-scheme: dark)").matches;

<Auth0ComponentProvider
  themeSettings={{ mode: prefersDark ? "dark" : "light" }}
>
```

<Callout icon="file-lines" color="#0EA5E9" iconType="regular">
**Next.js users:** Include your proxy mode props (`mode="proxy"`, `domain`, `proxyConfig`) on `Auth0ComponentProvider` as shown in [Configure Auth0ComponentProvider](/docs/get-started/universal-components/auth0-component-provider).

</Callout>
